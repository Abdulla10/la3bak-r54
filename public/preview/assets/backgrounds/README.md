# أصول خلفيات لعبنا

هني مكان الصور المعتمدة لاحقًا. الحزمة ما فيها صور نهائية؛ كل المعاينات الحالية تدرجات CSS مؤقتة.

ثبّت معرفات bg_01 إلى bg_40. حط الصورة المعتمدة باسم المعرف بصيغة webp، عقب حدّث art في background-catalog.ts لنفس المسار وmanifest.json لحالة available/approved. لا تضيف art قبل وجود الملف واعتماد صورته. هالعملية ما تغيّر الملكية ولا السعر، ولا تفعّل الشراء. السعر والتفعيل لهما اعتماد مستقل في إعدادات ShopCatalog الحالية.
