# تطبيق «لعبك» (Expo)

المرحلة الأولى: تطبيق جوال يفتح موقع la3bak.com من داخله، بألوان ستايل الشارات.
ما يغيّر شي في الموقع. كل المميزات الخاصة بالجوال تنضاف بعدين على نفس التطبيق.

## اللي تحتاجه
- كمبيوتر فيه Node.js (نسخة 20 أو أحدث).
- تطبيق **Expo Go** على جوالك (من App Store أو Google Play).
- حساب Expo مجاني (expo.dev). Expo Go يطلب تسجيل الدخول بنفس الحساب في الكمبيوتر والجوال.

## التشغيل أول مرة
```bash
cd mobile
npm install
npm run setup      # يركّب المكتبات بالنسخ المتوافقة مع Expo
npx expo login
npm start
```
بعدها يطلع كود QR:
- **آيفون:** صوّره بكاميرا الجوال وافتحه في Expo Go.
- **أندرويد:** افتح Expo Go واضغط «Scan QR code».

إذا الجوال والكمبيوتر مو على نفس الواي فاي: `npx expo start --tunnel`

## إذا Expo Go قال إن النسخة ما تتوافق
المشروع مضبوط على Expo SDK 58. إذا Expo Go اللي على جوالك أقدم:
```bash
npx expo install expo@^57.0.0 --fix
```
(بدّل 57 بالرقم اللي يقوله Expo Go)

## وش يسوي التطبيق الحين
- يفتح الموقع كامل داخل التطبيق، والجلسة تبقى محفوظة.
- زر الرجوع في الأندرويد يرجع داخل الموقع.
- أي رابط برا الموقع (واتساب، إنستقرام…) يفتح برا التطبيق.
- شاشة «ما فيه إنترنت» مع زر «جرّب مرة ثانية».
- زر «ثبّت كتطبيق» ما يطلع داخل التطبيق.
- الموقع يعرف إنه داخل التطبيق: `window.LA3BAK_APP` وكلاس `in-app` على `<html>`.

## معروف ولازم ينحل في المراحل الجاية
- **تسجيل الدخول بقوقل** ما يشتغل داخل التطبيق: قوقل تمنعه في صفحات الويب المضمّنة. يحتاج تسجيل دخول أصلي (Native).
- **المايك في غرف الصوت:** يطلب إذن المايك. على الأندرويد داخل Expo Go ممكن ما يشتغل كامل لين نسوي نسخة تطوير خاصة (development build).
- **الشحن داخل التطبيق:** أبل وقوقل يفرضون الشراء عن طريقهم للعملات والـVIP. لازم يتربط قبل الرفع على المتاجر.
- **الرفع على المتاجر:** يحتاج `eas build` و`eas submit` وحساب مطوّر في أبل وقوقل.

## إعدادات تقدر تغيّرها في `app.json`
- `extra.siteUrl`: رابط الموقع اللي يفتحه التطبيق (تقدر تحط رابط النسخة التجريبية).
- `extra.allowedHosts`: الدومينات اللي تفتح داخل التطبيق.
- `ios.bundleIdentifier` و `android.package`: معرّف التطبيق في المتاجر (`com.la3bak.app`). غيّره قبل أول رفع لأنه ما يتغيّر بعدين.
