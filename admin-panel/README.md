# لوحة تحكم لعبك (موقع منفصل)

- ملفات **الموقع** بمجلد `public/`، وملفات **لوحة التحكم** هنا بمجلد `admin-panel/`.
- اللوحة تكلّم نفس السيرفر (`/api/admin/...`). ما فيه سيرفر ثاني ولا قاعدة بيانات ثانية.

## طريقتين للفتح

1. **بدون إعداد:** افتح `https://la3bak.com/admin`.
2. **على دومين بروحها:** مثل `https://admin.la3bak.com`.
   - وجّه الدومين الفرعي `admin.la3bak.com` لنفس السيرفر (نفس nginx، شوف `deploy/nginx.conf.example`).
   - حط بالبيئة: `ADMIN_HOST=admin.la3bak.com` وأعد التشغيل.
   - بعدها `la3bak.com/admin` يحوّل تلقائياً على `admin.la3bak.com`، والموقع ما يقدّم ملفات اللوحة أبداً.

## الدخول على الدومين المنفصل

الدخول يكون برمز الإدارة (`ADMIN_TOKEN`) مع التحقق بخطوتين.
