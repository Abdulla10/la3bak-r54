## ماذا يوجد داخل الملف؟

- `public/`: الواجهة الحالية كاملة، الصور والخطوط وملفات الهدايا ثلاثية الأبعاد، الألعاب، الغرف، المتجر والملف الشخصي. يشمل غلاف مينابولي 3D والعنوان الثابت للدومين فقط.
- `src/`: أكواد الخادم ومحركات الألعاب والأنظمة المرتبطة بالحسابات والمحفظة والحفظ.
- `dist/`: بناء JavaScript الموافق للخادم، دون اعتماديات الجهاز.
- `db/`: مخطط MariaDB وترحيل حماية إنشاء الغرف؛ **مخطط فقط وليس بيانات لاعبين**.
- `ops/`: أدوات الحفظ والنسخ الاحتياطي والاستعادة والتحقق الموجودة في المشروع. لا تشغّل الاستعادة على الإنتاج من دون مراجعة.
- `scripts/` و`test/` و`tests/`: أدوات التطوير واختبارات المشروع الموجودة في مصدر R48. أضيف فحص نقل آمن باسم `scripts/smoke-real.mjs` بدل الأداة التاريخية التي كانت تفترض أسعارًا قديمة؛ لا يغيّر الفحص الاقتصاد.
- `acceptance-r50/`: اختبارات العنوان الثابت المستقلة وسجل الاختبارات النهائية.
- `docs/`: شرح التشغيل وأمثلة الاستضافة وأدلة الإصدارات والاختبارات.
- `package.json` و`pnpm-lock.yaml` و`tsconfig.json`: وصف الاعتماديات وقفل إصداراتها وإعداد TypeScript.

الكاميرا مستبعدة من الغرف، وقسم الأطفال غير معاد إلى الواجهة. تطبيق Expo منفصل وليس جزءًا من الموقع أو هذه الحزمة.

## تشغيل نسخة محلية

المتطلبات: Node.js 22 LTS وpnpm 10 واتصال بالإنترنت أول مرة لتنزيل الاعتماديات. الحزمة لا تضع `node_modules` لأنها تُثبَّت حسب نظام الجهاز من ملف القفل.

من داخل هذا المجلد:

```bash
corepack enable
pnpm install --frozen-lockfile
cp .env.example .env
mkdir -p data
pnpm run typecheck
pnpm run build
node --env-file=.env dist/server/index.js
```

افتح `http://127.0.0.1:3000`. ملف المثال مخصص لاختبار محلي على الجهاز، مع تعطيل الصوت وGoogle إلى أن توضع إعداداتهما الخاصة. لا تعرض هذا الإعداد على الإنترنت كما هو.

لتشغيل الاختبارات:

```bash
pnpm test
pnpm run smoke
node --test acceptance-r50/root-navigation.unit.cjs
```

الاختبارات تكتب بيانات اختبار مؤقتة محليًا. لا تُوجّهها إلى قاعدة بيانات أو مجلد بيانات الإنتاج. `scripts/verify-online.sh` أداة تاريخية تغيّر مساحة العمل وليست أمر نشر، وأداة `scripts/community/community-ui.cjs` محجوبة عمدًا لأنها تعتمد واجهة الأطفال المتقاعدة.

## الاستضافة الحقيقية

الموقع **ليس HTML فقط**. يحتاج عملية Node.js مستمرة وWebSocket وMariaDB للحفظ الدائم، وLiveKit للصوت. الخادم يرفض وضع الإنتاج دون `STORE=mariadb` و`WALLET_FILE` و`COOKIE_SECRET`.

راجع `docs/HOSTING-AR.md`. توجد أمثلة غير مفعلة في `deploy/`، وليست إعدادات الخادم الرسمي أو مفاتيحه. يجب تعديل المسارات والدومين وحماية HTTPS ومفاتيح الخدمات قبل الاستعمال. لا تضع مجلد المشروع كاملًا داخل مجلد ملفات عام؛ ملفات `src` و`db` و`ops` والإعدادات يجب أن تبقى غير متاحة من الويب.

**على الاستضافة الحالية:** احتفظ بملفات البيانات والإعدادات والمفاتيح الموجودة كما هي. لا تستبدلها بملف المثال ولا تنشئ قاعدة فارغة مكان القاعدة الحالية. نسخ الأكواد وحده ليس ترحيلًا لبيانات المستخدمين.

## ما لا يتضمنه الأرشيف ولماذا؟

لا يتضمن مفاتيح SSH أو كلمات المرور أو توكنات الخدمات أو شهادات TLS الخاصة أو ملفات بيئة الإنتاج أو جلسات الدخول أو بيانات المستخدمين أو أرصدة الحسابات أو تفريغ قاعدة الإنتاج. هذه ليست ميزات ناقصة من الأكواد؛ هي بيانات تشغيل خاصة يجب إبقاؤها منفصلة وآمنة.

الأصول العامة المشحونة مع الموقع موجودة كاملة. الملفات التي رفعها المستخدمون داخل مجلدات البيانات الخاصة، مثل صورهم ومنشوراتهم، ليست أصولًا عامة ضمن حزمة الأكواد ولا تُصدّر هنا. لا توجد ملفات اختصار أو روابط رمزية داخل الحزمة.
